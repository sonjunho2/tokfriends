## 5. EAS 빌드 실행 가이드

프로덕션 스토어 제출용 바이너리 빌드 명령어:

### 1) Android (Google Play용 AAB)
```powershell
cd apps/mobile
npx eas-cli build --platform android --profile production
```
*생성 파일: `.aab` (Google Play Console 내부 테스트/프로덕션 트랙 업로드용)*

### 2) iOS (App Store용 IPA)
```powershell
cd apps/mobile
npx eas-cli build --platform ios --profile production
```
*생성 파일: `.ipa` (App Store Connect TestFlight/App Store 제출용)*

### 3) 내부 기기 테스트용 APK (선택 사항)
```powershell
cd apps/mobile
npx eas-cli build --platform android --profile preview
```
*생성 파일: `.apk` (개발자 및 테스터 안드로이드 폰에 직접 설치 가능)*
