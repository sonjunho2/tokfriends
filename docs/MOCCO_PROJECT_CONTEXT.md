# 모꼬 (MOCCO) 프로젝트 컨텍스트 (Project Context)

> **MOCCO (모꼬)**: 전국 실시간 라이브 스트리밍, 1:1 대화, 커뮤니티(전체수다), 안심 에스크로 중고거래 & 본사 인증 직영 마켓 옴니 플랫폼

---

## 1. 서비스 개요 및 브랜드 정체성

- **서비스명**: 모꼬 (MOCCO)
- **슬로건**: "이웃과 나누는 실시간 라이브와 따뜻한 대화, 안심 마켓"
- **핵심 가치**:
  1. **실시간 소통 (Live & Chat)**: 언제 어디서나 1:1 라이브 방송 및 타임라인 기반 전체수다를 통해 동네 이웃과 소통.
  2. **가치 교환 (3D Gift & Points)**: 모꼬 꿀떡(Points)을 통해 라이브 방송 후원 및 1:1 대화방에서 화려한 3D 알파 선물 교환.
  3. **안전 거래 (Market & Escrow)**: 동네 주민 간 중고거래와 전국 산지직송 B2C 상품을 구매확정 전까지 보호하는 100% 안전 에스크로 결제.
  4. **신뢰 기반 인맥 (Trust & Social)**: 매너온도, 실제 동네 인증, 철저한 24시간 유해 차단/신고 관리.

---

## 2. 모노레포 아키텍처 및 프로젝트 구조

모꼬는 하나의 리포지토리에서 모바일 앱, 웹 포털/관리자 콘솔, 백엔드 API 서버를 유기적으로 통합 관리하는 모노레포 구조입니다.

```

├── apps/
│   ├── mobile/         # [모꼬 앱] React Native (Expo) - iOS & Android 앱
│   │   ├── src/
│   │   │   ├── api/          # 백엔드 REST API 클라이언트 및 인터셉터

│   │   │   ├── screens/      # 화면 (홈, 라이브, 모꼬챗, 마켓, 마이모꼬)

│       │   └── lib/          # 웹 API 클라이언트, 소켓 연동, 인증 컨텍스트
```

## 3. 5대 핵심 서비스 영역

### 1) 모꼬홈 (HOME)
- 스폰서 웰컴 배너 및 실시간 라이브 Top 3 랭킹 카드
- 현재 방송 중인 라이브 스트리밍 리스트
- 오늘의 마켓 특가 공구 및 추천 이웃 피드

### 2) 모꼬마켓 (MARKET)
- **동네 중고거래 (C2C)**: 이웃 간 직거래 및 안심 에스크로 택배 거래 지원
- **본사 직영 마켓 (B2C)**: 산지직송 신선식품 및 특가 상품
- **에스크로 안전결제**: 구매자가 '구매확정'을 누를 때까지 정산 대금을 보호하며, 반품/환불 및 분쟁 중재 지원

### 3) 모꼬 LIVE (LIVE)
- **Agora WebRTC 기반 고화질 저지연 실시간 스트리밍**
- 시청자 입장 시 환영 안내 및 실시간 채팅 스트림
- 3단계 티어(Tier) 3D 선물 이펙트 (볼빨간 모꼬, 구름카 질주, 골든 킹 축제)
- 방송 종료 시 "라이브가 종료되었습니다" 명확한 안내 화면 표출

### 4) 모꼬챗 (CHAT)
- **전체수다 (Suda Timeline)**:
  - 동네 이웃 누구나 1줄로 개설하는 실시간 수다방
  - 내가 개설한 방만 `🗑️ 삭제` 가능 (타인 개설 방은 `입장하기`)
  - 입장료(무료 / 100~1000 꿀떡) 설정 가능
  - 삭제 시 즉시 목록에서 제거되며 새로고침 후에도 복구되지 않음
- **1:1 대화방 (Chat Rooms)**:
  - 개설자-입장자 간 1:1 전용 대화
  - 대화 상대방의 실제 닉네임과 프로필 사진 정확한 표출
  - 읽지 않은 메시지 수(뱃지) 및 카카오톡 스타일 '1' 읽음 처리
  - 3D 선물 보내기: 실제 본인의 꿀떡이 차감되고 상대방에게 적립되며, 보낸 사람 본인의 닉네임으로 기록

### 5) 마이모꼬 (MY PAGE)
- 보유 꿀떡 잔액 실시간 조회 및 충전
- 내 프로필 사진, 지역, 소개글 관리
- 차단 회원 목록 관리 및 해제
- 판매자(입점사) / 크리에이터 센터 바로가기
